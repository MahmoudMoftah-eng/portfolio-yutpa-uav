# YUTPA UAV — Autonomous Mission Software

![YUTPA UAV](./WhatsApp%20Image%202026-09-27%20at%2020.44.27.jpeg)

## Overview
Developed Python/pymavlink mission software for a rotary-wing UAV using Pixhawk Cube Orange, Raspberry Pi 5, and ArduPilot.


## My contribution
- Implemented flight-mode transitions for the autonomous mission workflow.
- Generated dynamic figure-eight waypoint patterns.
- Developed target alignment and servo-triggered payload-release logic.
- Tested the workflow in ArduPilot SITL and Gazebo.


## Technologies
Python · pymavlink · ArduPilot · MAVLink · Pixhawk · Raspberry Pi 5 · Gazebo
